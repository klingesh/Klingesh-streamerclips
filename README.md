# StreamerClips

Brand assets for **StreamerClips** — a gaming / streaming brand.

The logo is a minimalist **SC monogram with an integrated play button**, in a
premium black + electric-blue color scheme. All marks are available as scalable
vector (SVG) and ready-to-use raster (PNG) files.

See [`branding/`](branding/) for all logo files and usage notes.

## Quick preview

| Glow | Flat |
|------|------|
| `branding/streamerclips_logo.png` | `branding/streamerclips_logo_flat.png` |

The **glow** versions have a neon edge-glow for a futuristic look; the **flat**
versions are cleaner and more minimal. Pick whichever suits the placement.
